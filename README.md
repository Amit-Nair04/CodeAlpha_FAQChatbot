# CodeAlpha Task 2: Chatbot for FAQs

## Internship
CodeAlpha Artificial Intelligence Internship

## Description
This project is an FAQ chatbot developed as part of the CodeAlpha AI Internship.

The chatbot uses NLP preprocessing and cosine similarity to find the most relevant FAQ answer.

## Technologies Used
- Python
- NLTK
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Gradio
- Google Colab

## Features
- FAQ-based chatbot
- NLP preprocessing
- TF-IDF vectorization
- Cosine similarity matching
- Interactive chatbot interface


## How to Run

1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Run all cells.
4. Open the Gradio link.
5. Enter a question.
6. View the chatbot response.
